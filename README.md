# SemiTalk (세미 토크)

학술제 참가신청서의 프로젝트 기획을 구현한 로컬 시연용 Flutter + FastAPI 프로젝트입니다. 

이전 버전의 변경 내용은 [한국어 버전 기록](CHANGELOG.md)에서 확인할 수 있습니다.
## 실행

Python 3.11 이상과 Flutter SDK가 필요합니다. API 키는 서버의 환경변수 또는 `backend/.env`에만 저장합니다. 앱 화면이나 GitHub에 넣지 않습니다.

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

현재 단계에서는 API 키가 필요 없습니다. 서버는 설정 없이 체험 모드로 시작합니다. 질문·계획·회의록은 규칙 기반 예시이므로 교안 내용을 실제 AI처럼 판단하지는 못합니다.

나중에 실제 AI를 연결할 때만 OpenAI Platform에서 프로젝트 API 키를 발급하고 `backend/.env.example`을 `backend/.env`로 복사해 키를 넣으세요. 그때 `DEMO_MODE=0`을 명시하고 서버를 재시작해야 실제 API를 호출합니다. `/health`의 `ai_ready`는 키 설정 상태만 나타내며 호출 성공이나 결제 설정을 보증하지 않습니다. `backend/.env`는 Git에서 제외됩니다.

다른 터미널에서:

```powershell
cd flutter_app
flutter create . --platforms web,android
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8000
```

Android 에뮬레이터에서는 `flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000`을 사용합니다. 포함된 Android manifest는 로컬 시연을 위한 인터넷 권한과 HTTP 연결 설정을 담고 있습니다. 배포할 때는 HTTPS 주소를 사용하세요.

`API_BASE_URL`을 정하지 않고 빌드하면, 배포된 웹에서는 같은 도메인의 `/api`(예: `https://내도메인/api`)를, 내 컴퓨터(localhost)에서는 `http://localhost:8000`을 자동으로 씁니다. API 서버가 다른 주소에 있으면 `flutter build web --dart-define=API_BASE_URL=https://api.내도메인`처럼 정해 주세요.

Swagger 문서는 서버를 켠 뒤 `http://127.0.0.1:8000/docs`에서 확인할 수 있습니다.

백엔드 통합 시험은 `backend`에서 `pip install -r requirements-dev.txt` 후 `python -m unittest test_flow.py`로 실행합니다. AI 응답은 시험에서 가짜 응답으로 대체하므로 API 키가 필요하지 않습니다.

## 시연 순서

1. 앱을 열면 고정한 스터디 채팅방으로 바로 들어갑니다. 왼쪽 메뉴에서 채팅방을 검색하고 이름을 바꾸거나 보관할 수 있습니다. 보관한 방은 다시 사용할 수 있습니다.
2. 새 방은 주제만 입력해 만들 수 있습니다. 교안은 골라 올리거나 화면에 끌어다 놓습니다(PDF·DOCX·PPTX·TXT·MD·이미지, 50MB 이하).
3. 채팅방에서 이번 주 범위와 복습 내용을 확인하고 바로 대화합니다. 학습 정리는 선택사항입니다. 교안이 없으면 목표를 기준으로 이야기합니다. 입력창의 클립이나 끌어다 놓기로 언제든 파일을 올릴 수 있고, 채팅에 첨부 기록이 남습니다. 사진과 스캔 문서는 서버 안에서 글자를 인식하고(Windows 내장 OCR, 다른 운영체제는 Tesseract `kor` 필요), 원본 없이 글만 저장합니다.
4. 마지막 주 전까지는 AI 동료가 공부한 것을 말하고 가볍게 물으며 이야기합니다. 마지막 주에는 채팅이나 파일로 발표하고 **발표 마치고 피드백 받기**를 누르면 동료별 피드백과 항목별 평가를 받습니다.
5. 주차를 마치면 채팅 안에 정리가 올라오고 같은 화면에서 다음 주차로 이어집니다. 기록 탭에서 스터디별 주차 정리를 봅니다.
6. 다시 볼 내용을 누르면 채팅에서 그 질문을 받고, 핵심을 답하면 복습이 완료됩니다.

진행 중인 랩미팅은 해당 주차의 **대화 이어하기**에서 다시 열 수 있습니다. 끝난 랩미팅은 스터디 화면의 회의록을 눌러 대화와 요약을 확인할 수 있습니다.

PDF 없이 만들면 핵심 개념·원리와 예시·복습 순서의 기본 계획을 제안합니다. 교안이 있는 스터디에서는 질문 아래의 **교안 N쪽 보기**를 눌러 해당 페이지의 추출된 원문을 확인할 수 있습니다. 교안을 교체해도 예전 질문이 참조한 페이지 내용은 유지됩니다. 원본 PDF 파일 자체는 저장하지 않습니다.
2주차부터는 **이전 주차 내용도 질문받기**를 켜거나 끌 수 있습니다. 기본값은 켜짐입니다. 켜져 있고 남은 복습 항목이 있다면 첫 질문에서 먼저 확인합니다. 끄면 질문 생성에 이번 주차 교안과 대화만 사용하며, 모든 AI 친구가 끝난 주차의 학습 정리를 기억한 상태는 유지됩니다. 다시 켜면 앞 주차의 교안과 완료된 스터디 기록도 질문에 사용할 수 있습니다.
각 주차에서 진행률과 못 공부한 내용을 저장하면 남은 일정 변경안에 반영됩니다. 변경안은 적용 전에 확인할 수 있습니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `backend/main.py` | FastAPI 앱 생성과 라우터 연결, 상태 확인 |
| `backend/auth.py` | 이름·비밀번호 로그인, 토큰 확인, 내 스터디인지 권한 확인 |
| `backend/routes/account.py` | 가입·로그인·로그아웃, 마이페이지, 모든 기록 한 번에 보기 API |
| `backend/common.py` | 공통 상수, PDF 추출, 스터디·세션 조회, 교안 쪽 고르기 |
| `backend/routes/studies.py` | 스터디 생성·채팅 목록·계획 수정 API |
| `backend/routes/sessions.py` | 질문·힌트·답변(채팅 속 일정 변경 포함)·주차 마무리·지난 대화 API |
| `backend/routes/records.py` | 회의록, 복습 항목, 성장 리포트 API |
| `backend/planner.py` | 채팅 메시지 속 일정·계획 변경 요청 해석과 반영 |
| `backend/ai.py` | 서버에서만 OpenAI Responses API 호출, JSON 결과 처리 |
| `backend/db.py` | SQLite 테이블과 연결 관리 |
| `flutter_app/lib/main.dart` | 앱 시작과 테마 |
| `flutter_app/lib/api.dart` | 백엔드 호출 |
| `flutter_app/lib/theme.dart` | 색상·크기 상수 |
| `flutter_app/lib/widgets/` | 공통 위젯, 말풍선·프로필 등 채팅 위젯 |
| `flutter_app/lib/pages/` | 로그인, 홈 탭(채팅·기록·마이), 채팅방, 스터디 만들기, 계획·기록 화면 |

AI 스터디원 프롬프트와 채팅으로 바꿀 수 있는 설정은 [docs/ai-prompts.md](docs/ai-prompts.md)에 정리했어요.

## 구현 메모

- PDF는 페이지별 텍스트를 SQLite에 저장합니다. 현재 주차 범위에서 발표문과 겹치는 단어가 많은 페이지 최대 3개를 AI 요청에 포함합니다. 질문에 표시되는 쪽수는 이 페이지들 중 하나일 때만 인정합니다.
- 동료마다 질문 관점과 사용자가 정한 초기 수준·이해 상태를 다르게 설정하고, 이전 질문/답변과 동료의 누적 이해 상태를 다음 질문에 전달합니다. AI가 다음 질문자를 고르고, 다른 동료가 필요할 때 짧게 대화에 참여합니다. 질문은 답변 후에만 다음으로 넘어갑니다.
- 교안이 있으면 관련 페이지를 골라 힌트 생성에도 사용합니다. PDF가 없으면 페이지를 표시하지 않습니다.
- 답변 반응은 직전 질문과 관련 교안 부분을 함께 전달해 생성합니다. 교안 근거가 없으면 정답이라고 단정하지 않습니다. 시연 모드는 교안 정답을 판정할 수 없다고 안내하며, 사용자 답변을 그대로 인용해 질문하지 않습니다.
- 최초 발표문, 답변, 재정리한 설명, 회의록을 각각 저장합니다. 사용자가 복습 필요로 표시한 질문과 AI가 제안한 확인 항목은 다음 주로 전달합니다.
- 학습 성장 기록의 숫자는 완료한 주차와 실제 질문·답변 횟수입니다. 처음과 나중의 설명은 사용자가 직접 쓴 글을 그대로 보여 주며, 자동으로 학습 효과 점수나 정답률을 추정하지 않습니다.
- 여러 기기 동기화, 음성, 실제 사람 초대는 현재 범위에 포함되지 않습니다. 외부에 공개하려면 HTTPS 뒤에서 실행하고 `ALLOWED_ORIGINS`와 `DOCS=0`을 설정하세요. 요청 제한은 서버 하나를 기준으로 메모리에서 셉니다.
- 질문의 정확성과 동료 같은 말투는 AI 출력에 영향을 받습니다. 교안 페이지 표시만으로 답변 내용의 사실성을 보증하지 않으므로 시연에서는 원문과 대조해야 합니다.
