# 학습 시스템 개선 방향 메모

작성일: 2026-11-24. 이 문서는 구현 계획을 논의하기 위한 메모이며, 아래 기능은 아직 구현되지 않았다.

## 사용자가 원하는 핵심 방향

주차별 마감에 맞춰 진도를 넘기기보다 **내용별 차시를 자기 속도로 공부**한다. 대화를 마치고 기록을 저장하는 행동과 다음 차시로 이동하는 행동을 분리한다. 같은 차시를 며칠에 걸쳐 이어 갈 수 있고, 사용자가 원할 때만 다음 차시로 넘어간다. 주간 기록이나 예상 일정은 진행을 돕는 정보로 남기되 학습을 막는 조건으로 사용하지 않는다.

채팅 중에는 AI 스터디원의 질문에 답할 수도 있고, 사용자가 궁금한 내용을 먼저 물어볼 수도 있다. 특히 AI가 질문한 직후라도 사용자가 “근데 AND랑 OR이 뭐였지”라고 물으면 직전 질문의 답변으로 평가하지 않고 **사용자의 질문에 먼저 답해야 한다**. 이후 원래 질문으로 돌아갈지, 새 주제로 이어 갈지는 대화 흐름과 사용자의 선택에 맡긴다.

## 현재 동작과 확인된 문제

- 현재 학습 범위는 `1/4주차`처럼 주차로 표시된다. 사용자가 `주차 마치기`를 누르면 회의록을 저장한 뒤 바로 다음 주차 대화가 시작된다.
- 코드에는 자유 대화 처리와 `user_question` 분류가 있지만, AI 질문이 진행 중일 때 체험 모드는 물음표(`?`, `？`) 유무로 역질문을 판별한다. 물음표 없이 “뭐였지”라고 물으면 일반 답변처럼 처리되어 “용어 뜻을 정확히 짚어 보자”라는 반응을 할 수 있다.
- 체험 모드는 실제 교안 이해나 개념 설명을 보장하지 않는다. 개념을 설명할 수 없는 상황이라면 질문을 무시한 일반적인 칭찬보다 한계를 분명히 알리고, 교안에서 확인할 위치 또는 학습 가능한 다음 행동을 안내해야 한다.

## 우선 검토할 변경

1. **학습 단위 분리:** 차시(배울 내용), 학습 대화(앱을 켜서 공부한 한 번의 활동), 주간 기록(달력 기준 보고)을 별도 개념으로 둔다. `오늘 공부 마치기`는 대화만 저장하고, `다음 차시로`는 사용자가 명시적으로 선택할 때만 진도를 바꾼다.
2. **사용자 발화 의도 구분:** 답변, 역질문, 운영 요청을 분리한다. 물음표뿐 아니라 “뭐였지”, “설명해줘”, “차이가 뭐야” 같은 표현과 대화 맥락을 본다. 애매할 때는 답을 억지로 평가하지 않고 짧게 확인한다.
3. **진행 중인 질문 보존:** 역질문에 답한 뒤 원래 AI 질문을 잊거나 답변 완료로 잘못 집계하지 않는다. 사용자가 원하면 원래 질문을 다시 보여준다.
4. **내용별 진도:** 교안 또는 사용자가 입력한 주제를 바탕으로 차시 목록을 만들고, 차시의 순서·내용을 사용자가 수정할 수 있게 한다. 날짜가 지났다는 이유만으로 미완료나 지연을 표시하지 않는다.

## 시스템 차원의 추가 개선 후보

아래 항목은 제안이며, 구현 우선순위는 함께 결정한다.

| 후보 | 사용자가 얻는 변화 | 첫 구현 범위 |
| --- | --- | --- |
| 복습 일정 관리 | 한 번 틀린 질문을 매주 무조건 반복하는 대신, 사용자가 `아직 어려움`·`이해함`을 표시해 다시 볼 시점을 조절한다. | 복습 항목에 상태와 다음 확인일을 저장하고 채팅에서 바로 완료·연기한다. |
| 교안 근거 추적 | AI의 설명이 어느 교안 쪽에서 왔는지 확인하고, 교안에 없는 설명을 구분한다. | 답변에 참고 페이지 또는 `교안 근거 없음`을 표시하고 원문을 열어본다. |
| 학습 내용 연결 지도 | 각 차시가 앞서 배운 개념과 어떻게 연결되는지 확인한다. | 차시 사이의 선행 개념과 관련 개념을 기록하고, 현재 차시에서 관련 복습으로 이동한다. |
| 기록 백업·내보내기 | 기기를 바꾸거나 시연 환경을 초기화해도 학습 기록을 보존한다. | 스터디별 계획·대화·회의록을 파일로 내보내고 다시 가져온다. 개인정보와 교안 원문 포함 여부는 사용자가 고른다. |
| 시연 환경 분리 | 학술제에서 반복 시연해도 실제 사용 기록이 섞이거나 사라지지 않는다. | 샘플 스터디를 별도로 제공하고 시연 데이터만 초기화한다. 체험 모드임을 명확히 표시한다. |

## 확인 기준

- AI가 질문한 직후 사용자가 `근데 AND랑 OR이 뭐였지`라고 물어도, 직전 질문의 답변으로 집계하지 않고 사용자 질문에 반응한다.
- 오늘 대화를 끝낸 뒤 다시 앱을 열면 같은 차시에서 이어진다. 사용자가 `다음 차시로`를 선택하기 전에는 진도가 바뀌지 않는다.
- 1주일 이상 같은 차시를 공부해도 `지연`으로 취급하지 않는다. 주간 기록은 실제 대화와 배운 내용만 요약한다.
- 체험 모드의 일반 응답을 실제 AI의 교안 검증이나 정답 판정처럼 표현하지 않는다.
